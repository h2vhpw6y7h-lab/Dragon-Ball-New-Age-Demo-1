# Dragon Ball New Age — Saga Saiyan (demo 0.5)

Fanowski, niekomercyjny prototyp RPG na iPhone'a i przeglądarki desktopowe.

**Gra:** https://h2vhpw6y7h-lab.github.io/Dragon-Ball-New-Age-Demo-1/?v=6

## Co działa
- Duża, proceduralnie rysowana mapa Ziemi 50×30 pól, sterowanie dotykiem, kliknięciem mapy, D-padem lub klawiaturą.
- Losowe walki: bandyta pustkowi, robot treningowy, Saibamen, zwiadowca Saiyan.
- Trzy fabularne starcia w kolejności: Saibamen → Nappa → Vegeta.
- Dialogi przed bossami oraz po zwycięstwach, powrót do eksploracji i treningu.
- Turowe walki z animowanymi kadrami, kontra, bloki, uniki, trafienia krytyczne, dodatkowe ciosy i wyświetlanie DAMAGE.
- Po awansie: +5 punktów atrybutów i +3 punkty skilli.
- Pięć gałęzi rozwoju, system odblokowań, wymagania poziomu, opanowanie technik, próba u Mistrza Roshiego.
- Zapis stanu w `localStorage` na urządzeniu.
- Poprzednia grywalna wersja: `demo-0.4-archive.html`.

## Pliki
- `index.html` — wejście gry i fallback.
- `saiyan.css` — oprawa i responsywność.
- `saiyan.js` — mapa, AI starć, fabuła i rozwój postaci.

## Ograniczenia
- Wersja testowa, nie gotowy produkt komercyjny.
- Część ilustracji postaci jest ładowana z zewnętrznych źródeł i może nie działać offline lub z czasem przestać się ładować.
- Nie ma jeszcze pełnej biblioteki własnych kadrów HD/4K, wielkich planet, prawdziwej animacji klatkowej ani instalatora iOS.
- Mapa jest grywalną mapą 2D, nie otwartym światem 3D.
